## 2. 企画コンセプト

線画イラストで描いた生活空間の一枚絵を提示し、**「この部屋、NGが3つあります」**として視聴者に探させる。
最後に3箇所を答え合わせし、「いくつ分かった?」をコメントで回収する。

### 採用理由(クイズ形式との比較)

| 観点 | 本企画の優位性 |
|---|---|
| 視聴維持 | 視聴者が画面を**凝視する**。「探す」行為自体が滞在時間を生むため、待機時間が離脱要因にならない |
| ループ再生 | 答え合わせ後に「もう一度見たい」が発生。実測で既に1.33〜1.6回/人のリピートがあり、増幅が狙える |
| コメント誘発 | 難易度を「3つ中2つは簡単、1つは難しい」に設計すると「2つしか分からなかった」が構造的に発生する |
| AI生成との相性 | **静止画1枚を長く見せるだけ**。動きの生成が不要で、HyperFramesの得意領域と一致 |
| テーマ一貫性 | 収納・片付けと完全一致。**シリーズ名・プロフィール文の変更が不要** |
| 誤情報リスク | 科学的主張ではなく「片付けの観点」に限定できるため、雑学系よりリスクが低い |

`【推測】` 上表の「視聴維持」「ループ再生」の優位性は、形式の構造から導いた想定であり、自アカウントの実データによる検証は未実施。検証は「7. 検証計画」で行う。

### 本企画で扱わないもの(スコープ外)
- 健康・衛生・食品の安全性に関わる主張(全面不採用)
- 特定メーカー・商品の否定
- 節約金額・省エネ効果などの数値主張(一次情報が取れない限り不採用)

## 4. 構成タイムライン(15秒 / 9:16縦型)

| 時間 | 内容 | 演出 |
|---|---|---|
| 0.0-2.0秒 | **問題提示** | 「この部屋、NGが**3つ**あります」+ 部屋名バッジ(テラコッタオレンジ)。背景には既に一枚絵を薄く表示し、**1秒以内に絵が見えている状態**を作る |
| 2.0-9.0秒 | **探す時間(7秒)** | 一枚絵をフル表示。**絵は一切動かさない**。画面下に残り時間バーのみ(数字のカウントダウンは視線を奪うため不使用) |
| 9.0-10.0秒 | **答え合わせ宣言** | 「答え合わせ」1秒のみ。タメはここだけ |
| 10.0-14.0秒 | **解答(3箇所 / 各約1.3秒)** | 該当箇所に順に丸を付け、一言解説を添える。**易→易→難の順**で出す(最後に驚きを置く) |
| 14.0-15.0秒 | **CTA** | 一枚絵の上にCTAを**重ねて**表示 → そのまま冒頭カットへ戻り、ループが自然に成立する |

**設計上の禁止事項**
- 探す時間中にヒントやチェックマークを出さない(答えバレ・視線分散)
- 解答を「上から順」に出さない。**簡単な2つを先、難しい1つを最後**に固定
- エンディングを静止カードで締めない(ループが切れる)

`【推測】` 「探す時間7秒」は本企画の中核仮説であり、現状の平均視聴時間(5.98秒)を超える設計。ここが最大のリスクでもあるため、7. でA/Bテストを行う。

## 6. 難易度設計ルール

コメントを構造的に発生させるための中核ルール。

- **1本につきNGは必ず3箇所。増減しない**
- **易2つ + 難1つ** に固定
  - 易: 一目で分かる(床の物、明らかな山積み)
  - 難: 言われて初めて気づく(位置の問題、動線の問題、数の問題)
- `【推測】` 想定正答率は易2つが70%以上、難1つが30%以下。**「3つ全部分かった」が少数派になる状態が理想**
- NGは画面内で**離れた3箇所**に配置する(1箇所に固まると同時に見つかる)
- 難のNGは、画面の**上部または端**に置く(視線は中央→下に流れやすいため) `【推測】`
